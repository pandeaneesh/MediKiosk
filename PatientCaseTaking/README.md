# 3D Pain Mapping & Patient Case Taking Module

Elderly-friendly 3D anatomical pain mapping module for MediKiosk.

## Features
- 3D Interactive Mannequin with surface-snapped pain markers
- High-contrast elderly-friendly UI with Theme A (Nordic Ice Blue)
- 100% verified height ratios and 180° auto-orientation
- Modular integration saving structured patient summary to `pain_summary.json`

## Quick Start
```powershell
pip install -r requirements.txt
python main.py
```
